# Atelier – Studio di Architettura

Sito web one-page realizzato per uno studio di architettura, con un design moderno, responsive e una modalità chiara e scura.

## Tecnologie utilizzate

- **HTML5** – Struttura della pagina.
- **CSS3** – Personalizzazione dello stile tramite SCSS.
- **SCSS (Sass)** – Variabili, nesting e gestione degli stili.
- **Bootstrap 5** – Layout responsive e componenti.
- **JavaScript** – Gestione del cambio tema Light Mode / Dark Mode.

## Funzionalità

- Navbar responsive con menu hamburger sui dispositivi più piccoli.
- Sezione Hero con presentazione dello studio.
- Sezione Servizi con tre card.
- Effetto hover sulle card.
- Sezione Contatti con form statico.
- Footer con informazioni e collegamenti.
- Pulsante per passare da Light Mode a Dark Mode.
- Transizione graduale durante il cambio dei colori.

## Responsive Design

Il sito è stato sviluppato con approccio **Mobile First**, utilizzando le classi responsive di Bootstrap 5.
